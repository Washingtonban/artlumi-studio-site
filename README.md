# Artlumi Studio

Site estático em português para `studio.artlumi.com.br`, com conteúdo sobre impressão 3D, peças autorais e projetos de tecnologia. Funciona sem build ou bibliotecas externas.

## Publicação

No GitHub Pages, selecione a branch `main` e a pasta `/ (root)` em **Settings → Pages**. O arquivo `CNAME` configura o domínio; o DNS também precisa apontar para o GitHub Pages.

Para conferir localmente, rode `python3 -m http.server` na raiz e abra `http://localhost:8000`.
